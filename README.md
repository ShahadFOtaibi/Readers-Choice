# 📚 Reader's Choice - Digital Library App (UI/UX)

> **UI/UX Design Case Study** | A personalized digital library interface for book discovery, shelf management, and e-reading.

---

> [!NOTE]
> **Project Goal:** Design an intuitive digital library experience that allows users to seamlessly discover, organize, rate, and read their favorite books in one place.

---

### 🚀 Key Features & App Sections

| Section | Description |
| :--- | :--- |
| **Authentication Flow** | Simple onboarding with clean login and account access. |
| **Discovery & Categories** | Browse books across multiple genres (Novels, History, Fantasy, Classics, etc.). |
| **My Books Shelf** | Track reading progress with custom statuses (*Reading*, *Want to Read*, *Finished*). |
| **Interactive Reader** | Clean, distraction-free typography layout for an optimized reading experience. |
| **User Settings** | Profile customization, security settings, and preference controls. |
